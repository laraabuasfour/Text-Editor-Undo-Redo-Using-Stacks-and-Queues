# Text-Editor-Undo-Redo-Using-Stacks-and-Queues
This project was developed for the Data Structures and Algorithms course.

It implements a text editor using:
- Undo Stack
- Redo Stack
- Queue
- Linked Lists in C

## Features
- Load text from file
- Insert text
- Remove text
- Undo/Redo operations
- Print stacks
- Save updated text to file

## Language
C
